# Python POO

Repositório contendo exercícios e implementações práticas de Programação Orientada a Objetos utilizando Python.

## Tecnologias

- Python 3

## Objetivo

Aplicar os princípios da Programação Orientada a Objetos na construção de soluções em Python, desenvolvendo código mais organizado, reutilizável e escalável.

## O que eu aprendi

- Classes e Objetos
- Encapsulamento
- Herança
- Polimorfismo
- Composição
- Abstração
- Métodos Especiais
- Boas práticas de POO
